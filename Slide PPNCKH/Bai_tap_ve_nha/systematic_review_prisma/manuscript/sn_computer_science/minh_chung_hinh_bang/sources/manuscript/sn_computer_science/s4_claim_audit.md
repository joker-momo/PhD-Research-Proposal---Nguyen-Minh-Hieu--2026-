# S4. Claim-level manuscript audit

Use a LaTeX source line to find the claim. The suffix distinguishes assertions at the same line. Page numbers are **one-based physical PDF pages**. Resolve primary report IDs to local originals and field-level locators in [the 46-study row map](s4_study_row_sources.csv). The [main S4 index](supplement_evidence_index.md) links the locked protocol, PRISMA records, outcome ledger, and exact row sources for Tables 1 and 4. For captions, legends, derived counts, and all equations, use the figure/table/equation register in that index. Source claims use retained accepted extractions and targeted checks against original PDFs. The row map inventories the accepted evidence per field, including partial and missing observations.

| --- | --- |

| RECORD | Recorded in the review protocol, data, coding, or manuscript. |
| DERIVED | Follows from the stated rule, operands, or assumptions. |
| PROPOSAL | Proposed workload, design, or reporting rule. |
| NARROWED | Revised because a broader interpretation exceeded the available evidence. |
| OPEN | Unresolved evidence, reporting, or author confirmation. |
